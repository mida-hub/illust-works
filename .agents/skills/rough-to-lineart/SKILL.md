# Rough to Lineart Skill

手描きのラフイラスト（iPhone等で撮影した写真）をもとに、チャットでコンセプトや修正要望を対話しながら清書（線入れ）し、最終的に背景透過済みのクリーンなPNG画像を出力するためのスキルです。

## ディレクトリ構造ルール

作品ごとに `artworks/<YYYYMMDD_テーマ名>/` ディレクトリを作り、以下の3段階のフォルダ構成で管理します。

```text
artworks/<YYYYMMDD_テーマ名>/
├── 1_raw/      # ① ラフ（初期データ・一切加工しない）
├── 2_work/     # ② 加工・修正サイクル用（01_resized.jpg, 02_lineart_v1.jpg, v2...）
└── 3_output/   # ③ 最終成果物（背景透過PNG・Tシャツプリント用）
```

## ワークフロー

### Step 0: 作品ディレクトリの初期化
新しいイラストを始める際は、`scripts/process_image.py init` で `1_raw` / `2_work` / `3_output` を一括作成し、`1_raw/` にラフ画像を配置します。

```bash
uv run .agents/skills/rough-to-lineart/scripts/process_image.py init artworks/<YYYYMMDD_テーマ名>
```

### Step 1: 前処理（リサイズ・トークン節約）
`1_raw/` 内の元画像を直接編集せず、`scripts/process_image.py` を使って長辺 1280px 程度にリサイズした画像を `2_work/01_resized.jpg` に出力します（HEIC 形式にも対応しています）。

```bash
uv run .agents/skills/rough-to-lineart/scripts/process_image.py resize <作品フォルダ>/1_raw/<ラフ画像> <作品フォルダ>/2_work/01_resized.jpg --max-size 1280
```

### Step 2: コンセプト確認・方向性の決定・ラフレビュー
いきなり清書を1案だけ作り始めるのではなく、**最初に方向性（線のタッチ・構図）を固めてから** `image-generator` サブエージェントを呼び出します。

1. **ヒアリング項目**:
   - 用途・配置（例：Tシャツの胸元ワンポイント、大きめプリントなど）
   - 線のテイスト・太さ（例：均一なベクター風、ゆるい手描き・かすれ線、過去作 `artworks/` や `shirts/` で近いテイストがあるか）
   - 文字入れの予定があるか（画像生成AIは文字が崩れやすいため、イラストのみ確定させた後にTシャツ作成サイト等で文字入れするかどうかを最初に決める）
2. **初期ラフの構図・Tシャツ映えレビュー**:
   - 必要に応じて別エージェント（`research` 等）にラフ（`01_resized.jpg`）を見せ、構図・バランス・Tシャツにしたときの見切れや余白の観点でレビューを受けてから清書に入る。
3. **初回生成（`02_lineart_v1.jpg`）**:
   - 方向性が迷う場合は、クォータ上限に配慮しつつテイスト違いの2〜3案を比較して大枠を決める。

**`image-generator` へのプロンプト指針：**
- 元ラフの構図、表情、主要なディテールを忠実に保つこと
- 背景は完全な純白（`#FFFFFF`）にし、紙の質感やグレーの影・汚れ・孤立した点（ゴミ）は一切入れないこと
- 線は黒一色（`#000000`）で、プリント時に飛んだり潰れたりしない適度な太さのきれいな主線（線画）にすること

### Step 3: 対話による修正サイクル（大枠確定 → 微調整）
生成した線入れ画像を `read_file` で確認・ユーザーに提示し、**まず構図・シルエット・タッチの大枠を確定させ、その後に目・表情・装飾などの微調整**へ進みます。修正版は `2_work/02_lineart_v2.jpg`, `v3`... と連番で保存します。

- **ベース画像の選択と固定箇所の明示**: `v2` 以降を生成する際は、元ラフからやり直すのか直前のベスト版（`02_lineart_vN.jpg`）をベースにするのかを明確にし、プロンプトに「変更箇所」だけでなく「維持する箇所（構図・表情・既存の線など）」を明記して意図しない崩れを防ぐ。
- **線画チェック基準**: `read_file` 時に、線の太さが均一・適切か、背景にグレーの滲みやゴミがないかを確認する。
- **採用版の明示**: 試行回数が増えた場合は、最終採用版（`vN`）をチャット上で明確にする。

### Step 4: 後処理（高解像度・背景透過PNG化）と仕上がり確認
線入れ画像が確定したら、`scripts/process_image.py` を使って白背景を透過（アルファチャンネル化）し、黒線のみのクリーンな高解像度 PNG（デフォルト2倍拡大：`--scale 2`）を `3_output/` に出力します。

```bash
uv run .agents/skills/rough-to-lineart/scripts/process_image.py transparent <作品フォルダ>/2_work/02_lineart_vN.jpg <作品フォルダ>/3_output/<テーマ名>_線画_透過.png --threshold 220
```

出力後は以下を確認し、必要に応じて `--threshold` や `--scale` を調整して再出力します：
- 白残り（フリンジ）や線の欠け・かすれが意図通りか
- 透過後に意図しない薄いゴミが残っていないか
- 絵の左右の中心点に不自然なズレがないか（Tシャツ中央配置時の確認）
